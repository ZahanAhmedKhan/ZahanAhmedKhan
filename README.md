## 🚀 Current Project

### 🚆 GTA Transit Reliability Tracker (in progress)
A data pipeline that loads the GO Transit schedule into PostgreSQL, answers questions about it with SQL, and shows the results in a dashboard. Live delay tracking comes next.

| Layer | Technology |
|-------|------------|
| Language | Python |
| Database | PostgreSQL |
| Dashboard | Streamlit (planned) |
| Data | GO Transit GTFS (Metrolinx Open Data) |
